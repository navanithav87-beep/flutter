# Flutter & Dart Development

A structured collection of **Dart programming fundamentals and Flutter development exercises**, created as part of my hands-on learning journey in application development.

## Overview

This repository covers core Dart concepts and introductory Flutter components, with individual programs demonstrating fundamental programming logic and UI development concepts.

## Repository Contents

| File              | Concept                                            |
| ----------------- | -------------------------------------------------- |
| `variables.dart`  | Variables, data types and basic input/output       |
| `operators.dart`  | Arithmetic, relational and logical operators       |
| `conditions.dart` | Conditional statements and decision-making         |
| `loop.dart`       | Iteration using Dart loops                         |
| `functions.dart`  | Function declaration, parameters and return values |
| `classes.dart`    | Classes, objects and basic OOP concepts            |
| `even_odd.dart`   | Even and odd number validation                     |
| `leap_year.dart`  | Leap year validation using conditional logic       |
| `container.dart`  | Flutter Container widget and basic UI styling      |
